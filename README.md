# SaticShield Homepage Transformation

A responsive, story-led static homepage concept for SaticShield.

## Run locally

Open `index.html` directly, or serve this folder with any static web server.

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

This is plain HTML, CSS, and JavaScript with no build step. It can be hosted on GitHub Pages, Netlify, Cloudflare Pages, Vercel, or any traditional web host.

For GitHub Pages, deploy the repository's `main` branch from the repository root.

## Structure

- `index.html` — page content and semantic structure
- `styles.css` — desktop design system and layout
- `mobile.css` — mobile art direction and responsive enhancements
- `script.js` — navigation, filtering, modal, animation, and image fallbacks
- `assets/` — locally hosted brand and product imagery
